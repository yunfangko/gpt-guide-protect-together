# GPT — Guide · Protect · Together Demo

這是一個不需後端、不需安裝套件的黑客松互動 Demo，以 Pupper v3 四足機器人為核心，呈現 AI 智慧導盲、Guardian AI 與 Safe Corridor。

## 執行

直接以瀏覽器開啟 `index.html`，或使用 GitHub Pages 等靜態網站服務發布。

## 線上部署

網站由 repository 根目錄的 `index.html` 啟動，並包含 `.nojekyll`，可直接使用 GitHub Pages 的 `main / (root)` 設定發布。

## Demo 操作

- 按「開始旅程」進入 Journey。
- 使用底部「下一步」播放完整流程。
- 鍵盤 `←` / `→`：上一步 / 下一步。
- 鍵盤 `S`：開啟 SOS 二次確認。
- 鍵盤 `R`：重播 Demo。
- 任一狀態皆可測試 SOS；確認後只會模擬通知緊急聯絡人，不會模擬報警。

## 新版互動架構

- 20 個同步故事狀態：公車規劃、搭乘、街道障礙、Guardian AI、Safe Corridor、紅綠燈、醫院室內導航、眼科、繳費、回家、找鑰匙與陪伴。
- 三視角：上帝視角、小晴視角、Pupper AI 視角。
- Compare Mode：同時比較小晴的感受與 Pupper 的 AI 推理。
- 每個事件拆解為 Sense → Understand → Assess → Decide → Act → Feedback。
- Demo Director：上一步、下一步、自動播放、暫停、重設與場景跳轉。

鍵盤：`←` / `→` 上下步、`P` 自動播放、`D` 展開 Director、`1`–`4` 切換視角。
